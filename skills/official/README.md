# 🏢 官方技能

Anthropic 官方发布的 Claude Code 技能。

| 技能 | 英文名 | 说明 | 热度 |
|------|--------|------|------|
| Word 文档处理 | docx | 创建、编辑和分析 Word 文档，支持跟踪修改、批注、格式保留和文本提取 | 🔥 98 |
| PDF 文档处理 | pdf | 提取文本、创建 PDF 文件并处理表单 | 🔥 97 |
| PPT 演示文稿处理 | pptx | 创建、编辑和分析 PowerPoint 演示文稿 | 🔥 95 |
| Excel 电子表格处理 | xlsx | 创建、编辑和分析 Excel 电子表格 | 🔥 94 |
| 技能创建器 | skill-creator | 创建扩展 Claude 能力的技能的指南 | 🔥 93 |
| MCP 服务器构建器 | mcp-builder | 创建 MCP 服务器以集成外部 API 和服务 | 🔥 92 |
| 前端设计 | frontend-design | 前端设计和 UI/UX 开发工具 | 🔥 90 |
| 文档协作编辑 | doc-coauthoring | 协作式文档编辑和共同写作 | ⭐ 88 |
| Web 应用测试 | webapp-testing | 使用 Playwright 测试本地 Web 应用 | ⭐ 88 |
| Web 制品构建器 | web-artifacts-builder | 使用 React 和 Tailwind 构建复杂的 HTML 制品 | ⭐ 85 |
| 算法生成艺术 | algorithmic-art | 使用 p5.js 和种子随机数创建生成式艺术 | ⭐ 80 |
| 画布设计 | canvas-design | 以 PNG 和 PDF 格式设计视觉艺术 | 📌 78 |
| 主题工厂 | theme-factory | 使用专业主题为制品添加样式或生成自定义主题 | 📌 72 |
| 内部通讯 | internal-comms | 撰写状态报告、通讯和常见问题解答 | 📎 68 |
| Slack GIF 创建器 | slack-gif-creator | 为 Slack 优化约束创建动画 GIF | 📎 65 |
| 品牌指南 | brand-guidelines | 将 Anthropic 品牌色彩和排版应用到制品中 | 📎 60 |

## 安装方式

```bash
# 从 Anthropic 官方仓库安装
git clone https://github.com/anthropics/skills.git /tmp/anthropic-skills
cp -r /tmp/anthropic-skills/skills/<技能名> .claude/skills/
```
